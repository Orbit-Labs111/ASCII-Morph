
ASCII Morph
An interactive React component that transforms images into animated ASCII art with a smooth reveal effect. Perfect for creative portfolios, experimental websites, and digital art projects.

✨ Features

- Animated ASCII image reveal
- Smooth transitions
- Responsive layout
- Highly customizable
- Built with React, TypeScript, and Vite

📦 Tech Stack

- React
- TypeScript
- Vite

🚀 Getting Started

Install dependencies

npm install

Start the development server

npm run dev

Build for production

npm run build

🎨 Use Cases

- Creative portfolios
- Interactive landing pages
- Digital art
- Experimental web experiences
